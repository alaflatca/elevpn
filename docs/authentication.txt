1. PSK와 HMAC Tag 추가

기존 패킷 구조
[header 12bytes][payload 가변bytes]
HMAC 추가 후 구조
[header 12bytes][payload 가변bytes][HMAC tag 32bytes]


PSK는 Pre Shared Key로 사전에 미리 서버와 클라이언트가 동일한 키를 가지고 있는 것을 의미하고
HMAC은 Hash-based Message Authentication Code 

Hash-based 는 SHA-256 같은 해시 함수를 기반으로 하고
Message Authentication Code는 이 메세지가 진짜인지 확인하기 위한 코드

HMAC tag는 payload만이 아니라 header + payload 전체를 대상으로 계산한다.
송신 측:
[header][payload]를 PSK를 사용해 HMAC-SHA256 계산
계산된 32byte tag를 packet 뒤에 붙여 전송

수신 측:
받은 데이터에서 [header][payload]와 [HMAC tag]를 분리
[header][payload]를 같은 PSK로 다시 HMAC-SHA256 계산
직접 계산한 tag와 받은 tag를 비교

두 tag가 같다면:
- 같은 PSK를 가진 쪽에서 보낸 packet으로 볼 수 있음
- header/payload가 중간에 변조되지 않았음을 확인할 수 있음

단, HMAC은 암호화가 아니므로 tcpdump로 보면 payload 내용은 여전히 평문으로 보인다.
