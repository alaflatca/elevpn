1.	VPN 서버 공인 IP로 가는 예외 route
의미상: server_ip/32 via real_gateway dev real_nic

2.	default를 tun으로 돌리는 route
의미상: default dev tun0

이 두 개를 넣는 이유는, 일반 트래픽은 tun0로 모으고 싶지만 VPN 서버로 보내는 UDP 자체는 원래 물리 NIC로 계속 나가야 하기 때문이다.
Linux routing은 더 구체적인 prefix를 우선 선택하므로 /32 host route가 default보다 먼저 잡힌다. default 는 fallback 경로다
